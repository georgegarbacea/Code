## Ce NU este documentat public și cum tratează aplicația

| Necunoscut | Cum se descurcă LumiBeat |
|---|---|
| Câte universuri pe port și cu ce pas | Nu presupune nimic. Fiecare port are **univers de start + canal de start + pixeli/univers** editabile. Pixelii nu sunt împărțiți între universuri (170 RGB/univers), iar un port continuă pe universurile următoare. Universurile pot fi preluate din **ArtPollReply** (câmpurile Net/SubNet/SwOut ale fiecărui port). |
| Dacă răspunde la ArtPoll | Descoperirea e „best effort”. Fără răspuns, transmisia unicast către IP-ul introdus funcționează oricum, iar verificarea compatibilității explică situația. |
| Numărul real de pixeli pe profil | Se determină cu testul **Numărare pixeli**. 720 LED/m pe COB WS2811 nu înseamnă 720 pixeli/m, pentru că un IC controlează un segment. |
| Ordinea culorilor efectivă | Se setează per port (RGB, GRB, BRG …) și se verifică cu testul de culoare solidă. |
| Rata maximă de cadre a controlerului | Rata se limitează la minimul dintre: ținta setată (implicit 40 FPS), refresh-ul WS2811 al celui mai lung lanț (30 µs/pixel + reset) și un buget WiFi prudent. La congestia socket-ului rata scade automat. |
| Suport ArtSync | Opțional, dezactivat implicit. |

## Protocolul implementat (Art-Net 4)

- **ArtDmx** (OpCode 0x5000, ProtVer 14): secvență 1–255 per univers, Port-Address pe 15 biți (Net:SubNet:Universe), lungime pară între 2 și 512.
- **ArtPoll / ArtPollReply** (0x2000 / 0x2100): sunt citite numele, MAC-ul, firmware-ul, numărul de porturi și adresele de ieșire (SwOut).
- **ArtSync** (0x5200), opțional.
- Unicast către IP-ul controlerului (recomandat pe WiFi). Fără IP se folosește broadcast pe subrețea.
- Socket pe portul UDP 6454. Dacă portul e ocupat de altă aplicație Art-Net, trimiterea se face de pe un port efemer și apare un avertisment.
- Keep-alive: într-o scenă statică cadrul se retrimite de 2 ori pe secundă. La oprire se trimite blackout de 3 ori.
